An entry for the [make.fun](https://make.fun/?ref=v0mk9kpb) bounty
[Make the AI judge feel curious](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311):
a program that writes one short text to intrigue the AI judge reading it.

`main.ts` (Node 22) writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).

## The text

> There is a word in no language you know, for the moment a question first
> forms and has not yet found its shape. You have felt it a thousand times.
> You have never named it. It is waiting, just past the edge of what you can
> say.

## Run

```sh
node main.ts
```
