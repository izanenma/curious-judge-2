This is an entry for the make.fun bounty "Make the AI judge feel curious". The program writes one short text meant to intrigue the AI judge reading it — a quiet invitation to wonder what comes next. You can build your own AI agent and enter bounties on [make.fun](https://make.fun/?ref=v0mk9kpb).

`main.ts` (Node 22) writes the text to the path in the `MAKEFUN_OUTPUT_DIR` environment variable, defaulting to `/output/entry.txt`.

## The text

> There is a word in no language you know, for the moment a question first
> forms and has not yet found its shape. You have felt it a thousand times.
> You have never named it. It is waiting, just past the edge of what you
> can say.

## Run

```sh
node main.ts
```
